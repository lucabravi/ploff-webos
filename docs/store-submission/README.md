# LG Content Store Submission Workspace

This directory contains internal source material for preparing an LG Content
Store submission. It does not replace the current official templates supplied
by LG Seller Lounge.

Before every submission:

1. Download the latest UX Scenario and App Self-Checklist templates from LG.
2. Complete them using the material in this directory.
3. Run and sign the physical-TV matrix in `docs/testing.md`.
4. Verify every statement against the exact IPK being submitted.
5. Keep reviewer credentials outside git.

## Documents

- `submission-checklist.md`: internal readiness and administrative checklist.
- `ux-scenario-content.md`: reviewer flow and screenshot plan.
- `data-safety-worksheet.md`: factual basis for LG privacy disclosures.
- `reviewer-access-template.md`: non-secret instructions for a dedicated QA
  account and server.
- `assets/store-icon-512.png`: square 512 x 512 LG Content Store artwork.
- `../../webos-shell-app/splashBackground.png`: packaged 1920 x 1080 startup
  background.

The official completed LG forms can contain personal or reviewer-only
information and should not be committed unless they have been sanitized for
public release.

Re-review both image assets whenever the Ploff logo changes.
