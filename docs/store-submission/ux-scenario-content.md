# UX Scenario Source Content

Use this material to fill the latest official LG UX Scenario presentation.
Screenshots should come from the fictional demo library or a dedicated QA
server, never a personal library.

## Test Preconditions

- LG webOS TV model and webOS version under test.
- Network requirements for local and remote scenarios.
- Dedicated reviewer Plex account and server instructions.
- Supported input: directional remote, media keys, and LG Magic Remote pointer.
- Expected initial language and how to change it.

## Reviewer Flow

1. **Launch and language**
   - Show the Ploff splash.
   - Select the interface language.
   - Explain local discovery and optional Plex account linking.
2. **Connect a server**
   - Select a discovered local server or enter an address manually.
   - Optionally link at `plex.tv/link`.
   - Select a Plex Home profile.
3. **Home**
   - Navigate Continue Watching, recommendations, and Recently Added rows.
   - Demonstrate directional focus and Magic Remote pointer behavior.
4. **Libraries**
   - Open a library and switch among recommendations, Continue Watching,
     Recently Added, catalog, and collections.
   - Demonstrate sorting, watched state, and advanced filters.
5. **Search**
   - Search with the on-screen keyboard.
   - Demonstrate optional numeric T9 input.
6. **Media details**
   - Select a season and episode.
   - Change audio, subtitles, and media version.
   - Toggle watched state and Watchlist.
7. **Playback**
   - Start or resume playback.
   - Seek with arrows and the timeline.
   - Open chapters, change tracks, and use intro/credit skipping.
8. **Settings and diagnostics**
   - Change interface and playback preferences.
   - Show LAN, Remote, or Relay route diagnostics.
9. **Offline behavior**
   - Explain which local features continue without Plex cloud access.
   - Show retry and manual server selection when a route is unavailable.
10. **Privacy and sign-out**
    - Open the privacy policy.
    - Disconnect Plex.
    - Delete all local Ploff data.
